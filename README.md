# School Sports League

Έτοιμη στατική ιστοσελίδα για GitHub Pages με online βάση Supabase και ασφαλή σύνδεση διαχειριστή μέσω email/κωδικού.

Οι επισκέπτες μπορούν μόνο να διαβάζουν ομάδες, πρόγραμμα, αποτελέσματα και βαθμολογίες. Μόνο λογαριασμός που έχει δηλωθεί στον πίνακα `admins` μπορεί να προσθέτει, να διορθώνει ή να διαγράφει δεδομένα.

## 1. Δημιουργία δωρεάν βάσης

1. Δημιούργησε νέο project στο [Supabase](https://supabase.com/).
2. Άνοιξε **SQL Editor → New query**.
3. Αντέγραψε όλο το περιεχόμενο του `supabase-schema.sql` και πάτησε **Run**.
4. Οι τέσσερις ενδεικτικές ομάδες θα προστεθούν αυτόματα.

## 2. Δημιουργία διαχειριστή

1. Άνοιξε **Authentication → Users → Add user → Create new user**.
2. Δήλωσε το email και τον κωδικό που θέλεις να χρησιμοποιείς.
3. Επίλεξε επιβεβαίωση του χρήστη, ώστε να μπορεί να συνδεθεί αμέσως.
4. Επίστρεψε στο **SQL Editor** και εκτέλεσε, αλλάζοντας το email:

```sql
insert into public.admins (user_id)
select id from auth.users where email = 'TO_EMAIL_SOU';
```

Η ύπαρξη λογαριασμού από μόνη της δεν αρκεί. Δικαίωμα αλλαγών αποκτά μόνο όποιος έχει προστεθεί στον πίνακα `admins`.

## 3. Σύνδεση της ιστοσελίδας

Στο Supabase άνοιξε **Project Settings → API**. Στο `config.js` συμπλήρωσε:

```js
window.SSL_CONFIG = {
  supabaseUrl: "https://TO_PROJECT_SOU.supabase.co",
  supabaseAnonKey: "TO_ANON_PUBLIC_KEY_SOU"
};
```

Το `anon public key` επιτρέπεται να βρίσκεται σε δημόσια ιστοσελίδα. Η ασφάλεια εξασφαλίζεται από τους κανόνες Row Level Security του `supabase-schema.sql`. Μη χρησιμοποιήσεις ποτέ το μυστικό `service_role key`.

## 4. Δημοσίευση στο GitHub Pages

1. Ανέβασε ολόκληρο το περιεχόμενο του φακέλου σε GitHub repository.
2. Άνοιξε **Settings → Pages**.
3. Επίλεξε **Deploy from a branch**, τη βασική branch και τον φάκελο `/ (root)`.
4. Άνοιξε τη διεύθυνση που θα εμφανίσει το GitHub.

Από εκεί και μετά πατάς **Διαχείριση**, συνδέεσαι και κάθε αλλαγή δημοσιεύεται αμέσως. Δεν χρειάζεται νέο commit για αποτελέσματα ή ημερομηνίες.

## Τοπική προεπισκόπηση

Από τον φάκελο `school-sports-league` εκτέλεσε:

```bash
python3 -m http.server 8000
```

και άνοιξε το `http://localhost:8000`.

## Προσωπικά δεδομένα

Η ιστοσελίδα αποθηκεύει και εμφανίζει μόνο ονόματα ομάδων και ομαδικά στοιχεία αγώνων. Δεν πρέπει να προστεθούν ονοματεπώνυμα, φωτογραφίες, στοιχεία υγείας ή άλλα προσωπικά δεδομένα μαθητών.
